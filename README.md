# Vent-aas

Vent-aas — это проект из серии работ '-aas', который является анонимным сервисом для обмена переживаниями, где каждый текст обретает цвет и настроение. Пользователь выбирает эмоцию (😊 радость, 😢 грусть, 😡 гнев, 😨 тревога, 🤔 размышление), отправляет сообщение, и оно превращается в уникальную цветную карточку. Другой пользователь получает случайное пожелание.
